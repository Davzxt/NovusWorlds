# Novus Worlds Godot Server

Servidor multiplayer dedicado em Godot .NET usando ENet. O client envia estado de posicao/rotacao/animacao e o servidor replica para os outros players.

Rodar local:

```powershell
powershell -ExecutionPolicy Bypass -File ..\tools\run-godot-server.ps1
```

Porta padrao: `53640`.
