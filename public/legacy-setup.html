Launcher Roblox 2012

Este modo substitui o client web. O site cria um ticket e chama o protocolo local novus://join ou novus-studio://edit.

O que o launcher precisa fazer

  1. Registrar os protocolos novus:// e novus-studio:// no Windows.
  2. Receber ticket, gameId e baseUrl.
  3. Baixar /api/legacy/join-script?ticket=....
  4. Baixar /api/legacy/avatar?ticket=... ou /api/legacy/avatar.xml?ticket=....
  5. Baixar /api/legacy/place/:id.
  6. Converter hats GLTF/GLB para mesh/acessorio legado quando necessario.
  7. Iniciar o client Roblox 2012 com o join script gerado.

Launcher incluido

Use a pasta launcher/ do repositorio. Copie config.example.json para config.json, configure os caminhos do Player/Studio 2012 e rode install-protocols.bat.
