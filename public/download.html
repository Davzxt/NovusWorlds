Novus Client e Studio

O novo Client e o novo Studio sao apps nativos em C++/Direct3D9. O site continua sendo a ponte para jogos, avatar, catalogo e mapas.

Os zips Windows contem os executaveis nativos. Extraia a pasta inteira antes de abrir.

Como usar

  1. Baixe e abra Install-NovusWorlds.cmd.
  2. O instalador baixa Client e Studio, instala em %LOCALAPPDATA%\NovusWorlds, registra novus:// e cria atalhos na area de trabalho.
  3. Depois disso, clique em Jogar na pagina de um jogo para abrir automaticamente com ticket.
  4. O multiplayer pequeno usa o WebSocket do site em /ws/game/:gameId.
  5. Use npm run native:build para compilar os executaveis Windows.
  6. Use npm run native:package para atualizar os downloads do site.

Importante

O site usa o Client nativo. O launcher abre o Player com ticket temporario, mapa JSON, avatar R6 e dados de servidor.

O alvo oficial desta etapa e Windows x64. Android fica fora ate o motor nativo estabilizar.
