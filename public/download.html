Baixar Novus Launcher

O site e a ponte. Para jogar ou editar no Studio 2012, o Windows precisa do launcher local e dos arquivos do client Roblox 2012 configurados no computador.

O pacote nao inclui RobloxPlayerBeta.exe ou RobloxStudioBeta.exe. Esses executaveis sao proprietarios; configure no launcher apenas uma copia local que voce tenha direito de usar.

Baixar launcher.js Baixar instalador Baixar config Guia

Instalacao rapida

  1. Crie uma pasta, por exemplo C:\NovusLauncher.
  2. Coloque os arquivos baixados nela.
  3. Renomeie config.example.json para config.json.
  4. Edite os caminhos de playerExe e studioExe.
  5. Execute install-protocols.bat.

Client 2012

O Novus nao baixa automaticamente arquivos proprietarios do Roblox. Voce precisa colocar uma build 2012 compatível no computador e apontar o launcher para os executaveis.

O launcher ja baixa join script, avatar, mapa JSON, gera `.rbxlx` basico e gera script Lua de appearance.
