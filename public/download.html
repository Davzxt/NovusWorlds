Novus Client e Studio

O novo client e o novo Studio sao feitos em Godot/C# e usam o site como ponte para jogos, avatar, catalogo e mapas.

Baixar instalador antigo Abrir Studio

O instalador antigo ainda existe enquanto a exportacao Godot nao fica pronta. A nova base esta no repositorio em godot-client, godot-studio e godot-server.

Como usar

  1. Abra o projeto godot-client no Godot .NET.
  2. Abra o projeto godot-studio no Godot .NET.
  3. Rode godot-server para multiplayer local.
  4. Para iOS, exporte o preset iOS em um Mac com Xcode.
  5. Use npm run godot:export:windows para gerar builds Windows quando os templates estiverem instalados.
