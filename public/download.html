Novus Client e Studio

O novo client e o novo Studio sao feitos em Godot/C# e usam o site como ponte para jogos, avatar, catalogo e mapas.

Os zips Windows contem os executaveis exportados e as pastas de dados necessarias do Godot/.NET. Extraia a pasta inteira antes de abrir.

Como usar

  1. Baixe e abra Install-NovusWorlds.cmd.
  2. O instalador baixa Client e Studio, instala em %LOCALAPPDATA%\NovusWorlds, registra novus:// e cria atalhos na area de trabalho.
  3. Depois disso, clique em Jogar na pagina de um jogo para abrir automaticamente com ticket.
  4. Rode godot-server ou o servidor dedicado exportado para multiplayer pequeno.
  5. Use npm run godot:export:windows para regerar os executaveis Windows.
  6. Use npm run godot:export:android para tentar o APK Android quando o export C# Android estiver liberado no ambiente.

Importante

O site usa somente o client proprio em Godot. O launcher abre o Player com ticket temporario, mapa JSON, avatar R6 e dados de servidor.

Para Android, o client ja tem preset, controles touch, SDK/JDK/NDK documentados e script de export. O Godot 4.6.2 .NET ainda marca Android/C# como experimental e bloqueou o APK neste ambiente.
