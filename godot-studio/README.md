# Novus Worlds Studio

Studio Godot .NET separado do client. Ele abre um mundo, mostra explorer simples, permite criar parte, spawn, duplicar, deletar e salvar JSON local.

Rodar local:

```powershell
powershell -ExecutionPolicy Bypass -File ..\tools\run-godot-studio.ps1 http://localhost:3000
```
